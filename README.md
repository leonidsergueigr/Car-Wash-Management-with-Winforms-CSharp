# Car Wash Management with WinForms C#

Application desktop C# / WinForms pour gerer une station de lavage.

Ce projet sert a pratiquer le developpement d'applications Windows avec Visual Studio, les formulaires, les interactions utilisateur et l'organisation d'une solution C#.

## Contenu

- Solution Visual Studio: `GestionnaireStationDeLavage.sln`
- Projet principal: `GestionnaireStationDeLavage`
- Interface WinForms pour les operations de gestion

## Lancement

1. Ouvrir `GestionnaireStationDeLavage.sln` avec Visual Studio.
2. Restaurer les dependances si necessaire.
3. Lancer le projet principal en mode Debug.
